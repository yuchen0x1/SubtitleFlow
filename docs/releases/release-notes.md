# SubtitleFlow 发布记录

## 0.0.2 · 2026-11-17（开发版本，尚未发布）

### 📢 版本概述

无需配置 AI 服务，即可读取网页原生字幕或导入字幕文件，并按视频时间轴显示原文。语音识别和机器翻译改为按需启用。

### ✨ 新增功能

- 默认仅显示原文，网页字幕和 SRT、VTT、ASS、SSA 文件可在无 AI 模式下使用。
- 弹窗可导入字幕文件，并显示按视频播放进度同步的字幕。
- 明确选择语音识别来源后才会请求音频采集，升级前保留的识别服务配置不会自动启动采集。
- 没有配置翻译服务时，启动字幕显示会回退到原文模式。

### ⚠️ 使用限制

视频画面中烧录的字幕属于图像内容；没有配置识别服务或 OCR 时无法自动提取。

## 0.0.1 · 2026-11-17

### 📢 版本概述

在 Chrome 和 Edge 的视频页面读取原生字幕或导入字幕文件，用随播放进度移动的字幕层显示原文。需要识别声音或显示译文时，可分别配置识别与翻译服务。

### ✨ 新增功能

- 打开网页视频后，可读取浏览器能访问的原生字幕并按视频时间轴显示。
- 没有原生字幕时，可选择本地 Whisper 或 OpenAI 兼容语音识别服务处理标签页音频。
- 可分别配置语音识别和文本翻译，支持双语、仅原文、仅译文三种显示方式。
- 字幕层支持拖动、样式预览、暂停、恢复和视频全屏跟随。
- 本地服务会报告模型下载、加载和推理错误，不生成虚假的识别结果。

### 📦 下载与安装

下载 [SubtitleFlow-extension.zip](https://github.com/yuchen0x1/SubtitleFlow/releases/download/v0.0.1/SubtitleFlow-extension.zip) 并解压。在 Chrome 或 Edge 的扩展程序页面打开开发者模式，选择「加载已解压的扩展程序」，选中含有 `manifest.json` 的目录，再刷新视频页面。

### 🔄 升级说明

这是首个公开版本。手动安装的扩展可在后续版本发布后，用新包更新原目录，在扩展程序页面重新加载，再刷新已打开的视频页面。

### ⚠️ 使用限制

烧录在视频画面里的字幕不是网页 `TextTrack`，需要配置 ASR 或后续 OCR；没有 AI 服务时仍可使用原生字幕、字幕文件和原文显示功能。
